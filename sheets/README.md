# Programa de pontos INOVACAR — Google Sheet (protótipo)

**Uma folha:** `Pontos` — `telemovel`, `nome`, `pontos` (à mão).

O site consulta via Web App (POST `{ telemovel }`) — **não** partilhe a folha.

Modelo: [modelo-clientes.csv](modelo-clientes.csv)

Operação: [OPERACAO.md](OPERACAO.md) · Colar no Sheet: [COLOCAR-NO-SHEET.md](COLOCAR-NO-SHEET.md)

## Instalar o Apps Script

1. Extensões → Apps Script → cola [`Codigo.gs`](Codigo.gs) → Guarda
2. Menu **Pontos INOVACAR → Preparar protótipo**
3. Implementar → App para a Web · Executar como: eu · Acesso: **Qualquer pessoa**
4. Copia o URL `/exec` para `PUBLIC_PONTOS_API`
