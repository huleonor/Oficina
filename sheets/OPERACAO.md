# Protótipo INOVACAR — operação

Uma folha: **Pontos**. Uma tabela:

| Coluna | O que fazes |
| --- | --- |
| `telemovel` | chave (9 dígitos) |
| `nome` | nome da pessoa |
| `pontos` | editas **à mão** |

## Site

O cliente mete o telemóvel → vê o saldo (coluna pontos).

## Menu

**Pontos INOVACAR → Preparar protótipo** (limpa e põe Ana / Bruno de exemplo).
